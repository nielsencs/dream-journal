# Dream Journal

Dream Journal is a simple browser-based app for recording dreams, organizing them by themes, and adding personal interpretations. Entries are saved in the browser on the device where they were created.

## How to Use

1. Select **+ New dream** to create an entry.
2. Add a title, then write the dream in the **Dream** panel.
3. Add comma-separated themes such as `flying, water, family`.
4. Use the **Interpretation** panel to record symbols, feelings, or waking-life connections.
5. Changes save automatically to the browser.

## Finding Dreams

- Use the search box to search all entry text, dream text only, or interpretations only.
- Select a theme tab to show entries with that theme.
- Use **Sort by date** to show newest or oldest dreams first.
- Select an entry in the list to edit it.
- Use **Delete dream** while viewing an entry to remove it.

## Running the App

Open `dream-journal.html` in a modern web browser. No installation or server is required.

Dreams are stored with browser `localStorage`, so clearing site data or changing browsers will remove or hide the saved entries.
